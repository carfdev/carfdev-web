# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities in this repository or the portfolio website privately to [security@carf.dev](mailto:security@carf.dev). Do not disclose vulnerability details in public issues or pull requests.

Include enough information to investigate:

- The affected page, file, or component, and the commit if applicable.
- Steps to reproduce the issue and its potential impact.
- A minimal proof of concept, if available, without real credentials or personal data.

For encrypted reports, use the [public PGP key](https://carf.dev/.well-known/security.asc).

The website's security contact information is also published in [security.txt](https://carf.dev/.well-known/security.txt). Preferred report languages are English, Spanish, and Swedish.
